# Tank Wars
A Scorched Earth-style artillery game in a single HTML file.

## Play
Open `tank-wars.html` in any browser, or play at [willchatham.com/tank-wars.html](https://willchatham.com/tank-wars.html)

## Features
- 2–8 players (1–4 human, rest AI)
- 24 classic weapons including MIRV, nukes, napalm, and more
- AI opponents with 6 personality types and 35+ quotes each
- Economy system with round multipliers (3x per round)
- Pre-game shop, round leaderboard, and match stats screen
- Greensleeves background music
- Multiple terrain and sky themes
